# 📝 Formulario
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

**Formulario de admisión** para proceso de inscripción: datos personales, secciones del proceso y envío — con imágenes ilustrativas en `img/`.

## 🚀 Cómo verlo
```
git clone https://github.com/RoDeluxe/Formulario.git
cd Formulario
# abre index.html con doble clic
```

## 🗂 Estructura
```
index.html    formulario de admisión
styles/       estilos
img/          imágenes del proceso
```
